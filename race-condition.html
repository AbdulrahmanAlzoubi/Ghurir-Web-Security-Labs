Race Condition

What it is

A race condition occurs when overlapping operations act on shared state and produce an unintended result. OWASP Top 10:2025 A06, Insecure Design, covers this design risk; CWE-362 describes concurrent execution using shared resources.

  • OWASP A06:2025 Insecure Design
  • CWE-362

Try it

Race a one-use $10 coupon or spend $15 twice from a $20 wallet. Every run starts with fresh data. Fixed mode accepts one request and rejects the extra attempt with 409 Conflict.

Why it matters

A race can break limits on coupons, transfers, or verification.

Real-world case · GitLab email verification

A PortSwigger researcher sent two email-change requests to GitLab at the same time. A confirmation message sent to the researcher’s inbox could verify a different address. This disclosed finding shows how overlapping requests can interfere with shared state, as they do in the coupon lab.

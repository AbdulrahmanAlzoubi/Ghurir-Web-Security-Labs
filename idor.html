Insecure Direct Object Reference

IDOR happens when an app uses an ID you supply to look up a record without checking whether you can access it. Changing that ID can reveal somebody else’s record.

  • OWASP A01:2025 Broken Access Control
  • CWE-639

Why it matters

An attacker could read private orders or documents by changing their IDs.

Real-world case · First American (2019)

First American’s document-sharing app let users change the document ID in a link and open other customers’ documents. The U.S. SEC documented the flaw in its 2021 order. Changing an invoice number in this lab models the same missing access check.
